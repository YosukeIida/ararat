# Ararat と Yab の UI 設定値

参照した Yab のコミットは `5a9b57a94cdfbc9bb181b8bab26c1f0611ddf245`、Ararat の基点は `3e7509f` である。節番号は [Ararat の設計文書](../architecture.ja.md) を指す。Cra 欄は [Cra の調査記録](cra-ledger.ja.md)、設計文書の第 7 節、および手元の Cra のコミット `68108cea7a2f8759c1da7e7756abf446f6c76efe` に基づく。過去の Yab の画面実測は [観察記録](yab-observed.ja.md) にある。ソースの設定値と過去の画面実測は一致しない場合がある。

「同等」は同じ操作に使う値、「一部同等」は関連する操作に使う値を指す。「なし」は実装方式が異なるか、対応する機能がない。「未確認」は、対応する操作または値をソースから特定できなかった項目である。Cra 欄の「—」は値が未確認であることを示す。

## Arc の実測値との差

Ararat の浮動サイドバーは、ウィンドウ端の 5 pt 以内で 150 ms 待機して表示を始める。スプリングの応答時間は 150 ms、減衰比は 0.84、退場は約 90 ms である。ウィンドウの外側 250 pt、反対側はパネルの端から 72 pt まで表示を保つ。Yab は待機 300 ms、内側の検出範囲 3 pt で、同じディスプレイ上では外側の距離に固定の上限がない。スプリングの応答時間は 210 ms、減衰比は 0.78、退場は 120 ms。浮動インセットは Ararat の 5 pt に対し 0 pt である。過去の Yab 実測では検出範囲 12 pt、待機約 330 ms、応答の推定値 170 ms だった。実装の比較にはコミット時点の値を使う。[Arc の実測](arc-ardia-observed.ja.md)、[Yab の過去の実測](yab-observed.ja.md)、[Lights.swift:648-685](https://github.com/yetanotherbrowser/yab/blob/5a9b57a94cdfbc9bb181b8bab26c1f0611ddf245/Sources/Fast/Lights.swift#L648-L685)、[Lights.swift:687-727](https://github.com/yetanotherbrowser/yab/blob/5a9b57a94cdfbc9bb181b8bab26c1f0611ddf245/Sources/Fast/Lights.swift#L687-L727)、[Peek.swift:848-854](https://github.com/yetanotherbrowser/yab/blob/5a9b57a94cdfbc9bb181b8bab26c1f0611ddf245/Sources/Fast/Peek.swift#L848-L854)、[Design.swift:548](https://github.com/yetanotherbrowser/yab/blob/5a9b57a94cdfbc9bb181b8bab26c1f0611ddf245/Sources/Fast/Design.swift#L548)

Yab はドラッグ中に周囲の行をずらす。Arc の記録では行は動かず、2 pt の挿入線が出る。Cra が記録した Arc のコマンドバーは幅 766 pt、入力欄 60 pt、結果行 50 pt である。Yab のオーバーレイは通常で最大幅 750 pt、入力欄 58 pt、結果行 38 pt、コンパクト表示では順に 540 pt、52 pt、40 pt である。Cra はリスト端の罫線を 1 pt と記録した。色は明色で黒 5%、暗色で白 7%。Yab はマスクと下端のグラデーションを使う。Yab の space ドックはドットのセルも収まらない場合にスクロールできる。[Arc の実測](arc-ardia-observed.ja.md)、[Cra の調査記録](cra-ledger.ja.md)、[ColumnDrag.swift:831-854](https://github.com/yetanotherbrowser/yab/blob/5a9b57a94cdfbc9bb181b8bab26c1f0611ddf245/Sources/Fast/ColumnDrag.swift#L831-L854)、[Omnibox.swift:67-91](https://github.com/yetanotherbrowser/yab/blob/5a9b57a94cdfbc9bb181b8bab26c1f0611ddf245/Sources/Fast/Omnibox.swift#L67-L91)、[SpaceFoot.swift:198-225](https://github.com/yetanotherbrowser/yab/blob/5a9b57a94cdfbc9bb181b8bab26c1f0611ddf245/Sources/Fast/SpaceFoot.swift#L198-L225)
